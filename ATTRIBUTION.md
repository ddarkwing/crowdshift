# Runtime libraries and data acknowledgements

- MapLibre GL JS — interactive map renderer.
- deck.gl — GPU geospatial layers (heatmap, hex aggregation, arcs, event points).
- Globe.gl — interactive landing-page globe.
- NASA EOSDIS GIBS — optional MODIS Terra true-color imagery layer. Please retain NASA/EOSDIS attribution.
- Open-Meteo — weather and air-quality API integration.
- MeteoAlarm — official warning context feed.

User-provided source archives were used to pin the intended library families/versions and examples. Browser builds are loaded from public distribution CDNs at runtime because the supplied repository source archives do not contain prebuilt dist artifacts.
